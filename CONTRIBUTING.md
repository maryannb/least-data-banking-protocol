***The LDBP is a living standard.***

If you have improvements or required changes for your specific use case, please submit a proposal. 

Approved changes will be integrated into the official M. Belarmino Specification to ensure industry-wide interoperability.

Proposals can be submitted via GitHub Pull Request or emailed directly to Mary Ann Belarmino.

Below is a template you can use to propose changes.
